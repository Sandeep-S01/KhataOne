# Overview layout concept 2

Status: static PNG for visual approval, not implemented.

[Open version 2](overview-proposal-v2.png)

The user's additional reference suggests a stronger shell: one global header with firm context and a simpler navigation rail. This proposal adopts that principle and develops a different, compact summary band and worklist using the original Overview data.

## Design judgment

This direction is preferable for repeated desktop CA work: the single firm context removes duplication; a narrower navigation rail leaves more room for invoice and amount columns; one divided summary surface reduces visual fragmentation; and the compact worklist brings the eight-record snapshot higher up the composition. Outlined Review buttons make individual row actions easier to identify while retaining one solid primary action in the page header.

The reference's charts, percentage trends, time-saved claims, named user/photo, notifications, and GST-filing labels were not adopted because this page does not supply the evidence for them. Confidence remains numeric and neutral; no new risk thresholds are proposed. Counts and missing-value semantics follow the original screenshot.

Tradeoffs: removing sidebar group labels slightly reduces explicit navigation categorization; separators retain three clusters. The summary band needs a stacked or two-column treatment on smaller screens. Compact row buttons need larger touch targets on mobile. Those behaviors are not verified by a desktop PNG.

## Review limits

The generated concept was visually inspected: all eight table rows are visible, invoice numbers remain on one line, amounts align, and missing amounts are not converted to zeros. Logo, font, icon, and exact record-text rendering remain generative approximations; retain the actual KhataOne logo and source data if implemented. The image is a layout approval artifact, not a pixel-exact asset specification or evidence of implemented functionality. Existing version 1 is retained for comparison.

No application, shared shell, backend, query, or other page changed. Only this concept, its notes, and the project tracker were updated. Runtime checks are not applicable to the PNG/document-only change.
